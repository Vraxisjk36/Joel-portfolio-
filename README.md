# Joel Kazadi — Portfolio V1

A static, responsive personal portfolio built with HTML, CSS and vanilla JavaScript. No package installation, API keys or paid infrastructure are required.

## Run

Open index.html, or serve the repository root using `python -m http.server 8000` and open http://localhost:8000.

## Publish with GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save. GitHub will provide the actual deployment URL when ready.

## Included

- Skip-enabled cinematic intro, oversized typography, scroll-driven text, responsive navigation.
- Seven featured projects and three archive projects; filterable horizontal gallery, case-study dialogs and source links.
- Actual supplied portrait (small monochrome crop embedded in assets/portrait.svg).
- About, timeline, employment, education, skills, leadership and contact.
- Printable CV at cv.html (use the print/save as PDF control).
- VEIL, Chronos and Cedar & Flame source-based concept previews under demos/. These are fictional and have no real reservation capability.

## Before job applications

- Replace the illustrative project artwork with actual screenshots or recordings. The current artwork is explicitly labelled; it is not a product screenshot.
- Replace the low-resolution portrait preview with a high-resolution version of the supplied photograph. Use a local asset, not an external portrait URL.
- Verify VraxisRSVP, Vraxis Drop and Play Store deployment links.
- Do not publish internal CRC screenshots or data without permission. Only high-level information is included.
- Verify every claim and personal contribution. PersonaOS and Aether have unfinished features; no fake metrics or awards should be presented as fact.
- Check concept preview imagery licences, asset loading, mobile behavior, accessibility, keyboard focus, reduced motion, and the printed CV.
- LinkedIn is intentionally omitted. No analytics or tracking scripts are installed.

The portfolio itself is static and does not need Supabase or a backend. The concept previews retain their original external fonts and libraries where applicable.
